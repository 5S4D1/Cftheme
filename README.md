# Cftheme
Theme extension for Codeforces.

## file structure

```txt
codeforces-themes/
│
├── manifest.json             # configure file
├── content.js                # theme switchinig
│
├── styles/                   # theme css folder
│   ├── base.css              # base css for all theme
│   └── themes.css            # theme css for all themes
│
├── popup/                    # popup folder
│   ├── popup.html            # popup UI html
│   ├── popup.css             # popup css
│   └── popup.js              # সিলেক্টেড থিম সেভ করার লজিক
│
└── icons/                    # icons folder
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```
